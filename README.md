# Silah Uretim Modpack - Oyuncu Guncellemeleri

Bu depo modpack'in oyuncu tarafi guncellemelerini tasir.

## Arkadaslar icin kurulum (bir kere)
1. `guncelle.bat` dosyasini indir.
2. CurseForge'da profile sag tikla -> **Open Folder** -> dosyayi bu klasore koy.

## Her oynamadan once
`guncelle.bat`'a cift tikla. "Guncelsin" diyorsa oyunu ac; yeni surum varsa kendisi indirir.
Kendi ayarlarina (tuslar, gorus mesafesi, harita, dunyalar) dokunmaz; her guncellemeden once yedek alir.

## Icerik
- `surum.txt`: son surum numarasi
- `guncelleme.zip`: kubejs, config ve gerekli jar'lar
